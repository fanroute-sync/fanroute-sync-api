## 결정 및 근거

### 공연 공식 시작 시각과 템플릿 시간 분리

- 선택지: 템플릿의 시간만 사용하거나, 공연 정보에도 공식 시작 시각을 저장한다.
- 선택: 공연 정보에 공식 시작 시각을 저장하는 방향을 권장한다.
- 근거: 템플릿 시간은 일정 배치용이고, 공식 공연 시간은 템플릿과 독립적인 원본 메타데이터다.
- 후속 결정: 다일 공연의 회차별 시각을 위해 `Concert.startTime` 또는 `ConcertSession` 중 하나를 확정해야 한다.

### 여행 스타일 입력 시점

- 선택지: 여행 계획 생성 시 필수 입력하거나, 생성 후 상세 화면에서 입력한다.
- 선택: 와이어프레임 Rev.3에 따라 생성 후 입력을 기준으로 한다.
- 근거: 숙박 정보·여행 스타일은 전체 여행 일정 생성 완료 후 여행 상세 상단 메뉴에서 진입한다.
- 위험: ERD 초안의 `travel_intensity not null`과 충돌하므로 DB 제약 확정 전 합의가 필요하다.

### 장소 참조 방식

- 선택지: TourAPI 외부 ID 문자열 저장 또는 `Place` FK 저장.
- 선택: 미결정으로 기록한다.
- 근거: ERD 초안은 문자열을, 기존 프로젝트 구조와 최초 구현 범위는 `Place` 참조를 가리킨다.
